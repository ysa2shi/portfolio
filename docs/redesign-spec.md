# UI刷新 仕様(Stardust テーマ)

状態: 実装済み(手順1〜6)。残りは見た目の最終調整(フォントの見直しなど)。見た目の基準は `docs/mocks/mock-stardust-site.html`。

## 1. 方針
- 全体の色味を、銀白・水色・星雲の緑・金の差し色・紫で統一する。
- 背景は白基調。夜空はダークモードと Skills セクションだけに使う。
- CSS 優先。素の TS で足りる範囲に収め、フレームワークは追加しない。
- AIっぽさ・医療っぽさを避ける。色は面積を絞り、金は「光る瞬間」だけに使う。
- 日本語メイン。英語ページは `/en`(トップ・Blog・Articles)に最小限で用意した。ブログ記事は日本語のみ。

## 2. 配色トークン
| 役割 | ライト | ダーク |
|---|---|---|
| 背景 `--bg` | `#f9fbfd` | `#070d1f` |
| 面(銀) `--surface` | `#f1f6fa` | `#0f1a36` |
| 淡い水色の面 `--wash` | `#edf5fa` | `#0d2540` |
| 文字 `--ink` | `#1d2a3a` | `#eaf2ff` |
| 補助文字 `--sub` | `#5b6676` | `#9fb2d0` |
| 線 `--line` | `#dfe7ee` | `#1a2748` |
| 主アクセント(空色) `--accent` | `#3a9fcb` | `#6cc6ec` |
| 緑 `--accent-2` | `#3aa86f` | `#86cfb4` |
| 金 `--gold` | `#d99a00` | `#f5cf55` |
| 紫 `--violet` | `#7a4fb0` | `#a98be0` |

使い分け:
- **空色**: リンク、主ボタン、星図の線、実務の星。
- **緑**: ナビの下線(ホバー・現在地)、カード・ボタンのホバー、タグ、見出しグラデーション。
- **金**: 主戦力の星、セクション見出しの ✦、光。ほかには使わない。
- **紫**(控えめ): キーボードフォーカスの輪、コードのキーワード、タグのホバー枠、フッター上の線。テキスト選択色・Skills の光には使わない。
- 見出しグラデーション: 空色 → 緑 → 金(ヒーローのキーワードと細い区切り線だけ)。
- 引用は緑にせず、銀の面+グレーの左線。

## 3. テーマ(ライト/ダーク)
- 初期値は**ライト**。OS 設定は参照しない。
- ヘッダーのボタンで手動切り替え。選択は `localStorage` に保存し、保存できない環境でも動く(try/catch)。
- 初回描画のちらつきを避けるため、`<head>` の最小のインラインスクリプトで `data-theme` を先に設定する。
- ダークの全体背景は単色の濃紺。星空と星雲は Skills パネルだけ。

## 4. 共通 UI
- **ヘッダー**: 左にサイト名(名前のみ)、右にナビ(Home / Blog / Articles)とテーマ切り替え。スマホは既存のメニューを踏襲。現在地は緑の下線。
- **フッター**: 著作権と外部リンク。上に紫→空色の細い線。
- **セクション見出し**: 既存のフォントのまま+小さな金の ✦。
- **フォント**: 既存のフォントを使う。見た目を見て、最後に見直す(明朝系はモックの仮案)。
- **カード**: 銀の面+細い線。ホバーで緑の枠と影、少し浮く。
- **ボタン**: 主ボタンは空色の塗り、副ボタンは枠のみ。ホバーで緑の輪。
- **アクセシビリティ**: `prefers-reduced-motion` で全アニメーションを停止。フォーカスは紫の輪。

## 5. ページ別
既存の構成に沿って分ける。

| ページ | 内容 |
|---|---|
| トップ `/` | Opening(ヒーロー)→ Profile → Timeline → Skills → LatestPosts → LatestArticles |
| `/blog` | 記事一覧(カード) |
| `/blog/[slug]` | 記事ページ(本文、引用、コード、リンクカードを新テーマに) |
| `/articles` | Zenn 記事一覧 |
| 404 / 500 | 新テーマのエラーページ(星の装飾は控えめに) |

### ヒーロー(Opening)
- 文字(見出し・紹介文・ボタン2つ)+右側に小さな星座(金の ✦ 1つ、空色の星2つ、銀白の星3つ、細い水色の線)。
- 星は6秒周期でゆっくり明滅。スマホは幅を狭めて薄く表示。

### Skills
- 常に夜空のパネル。深い紺の空、小さな星と ✦ のきらめき、下部に水色寄りの淡い星雲(緑は抑える)。
- 表示は「星図 / リスト」の切り替え。PC 幅の選択は `localStorage` に記憶。**スマホ幅(640px以下)は常にリスト**で、切り替えボタンは出さない。
- 星の種類: 主戦力=金の ✦、実務で使用=空色の点、個人開発でよく使う=緑の輪、試している=緑の点線の輪。カテゴリの色分けはしない(凡例の文字ボタンで絞り込み)。
- 星図: 触れるとつながりのある星だけが浮かぶ(線は淡い黄)。クリックで固定。補助線は同心円と十字。
- リスト: カテゴリごとのカードにチップを並べ、主戦力が先。チップを押すと、つながりのある技術が明るくなり、同じカードの下に「つながり: …」を表示(ホバーでは文字を出さない)。
- データは `skills.ts` 1か所(ID、分類、座標、つながり、ビルド時検証)。星座に載せるのは約20個まで。

## 6. 実装の範囲と順序
全ページを対象にする。順序の目安:
1. トークンとテーマ(CSS 変数、切り替え、`BaseLayout`)
2. ヘッダー/フッター
3. 共通部品(カード、ボタン、タグ、見出し)
4. トップの各セクション(Opening → Profile → Timeline → Skills → Latest → Contact)
5. ブログ一覧と記事ページ(`MarkdownPostLayout`、リンクカード CSS)
6. Articles、404、500

## 7. 範囲外・注意
- 英語ページは最小限(トップ・Blog・Articles)のみ。記事ページの英語化は対象外。
- ポートフォリオ紹介記事(`portfolio-site.md`)は触らない。
- 水表現は使わない(過去に破棄済み)。
- Cloudflare ダッシュボード側の設定は対象外。
